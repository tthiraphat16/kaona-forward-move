# Kaona Campaign Hub

---

MASTER PROMPT — KAONA PARTY CAMPAIGN WEBSITE

สร้างเว็บไซต์หาเสียงอย่างเป็นทางการสำหรับ “พรรคก้าวหน้า (KAONA PARTY)” สำหรับการเลือกตั้งคณะกรรมการสภานักเรียน โรงเรียนเมืองนครศรีธรรมราช ปีการศึกษา 2569

เว็บไซต์ต้องมีภาพลักษณ์ Premium / Modern / Bold / Editorial / Political Campaign Website ดูเหมือนเว็บไซต์แคมเปญระดับมืออาชีพ ไม่ใช่เว็บไซต์โรงเรียนทั่วไป

เว็บไซต์ต้องเน้น Visual Storytelling, Typography, Motion, Interactive UI และ Mobile Experience เป็นพิเศษ
